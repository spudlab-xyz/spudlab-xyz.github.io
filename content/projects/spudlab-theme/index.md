Spudlab theme is the visual and structural foundation for this website. It provides responsive layouts for homepages, sections, articles, taxonomies, and error pages while keeping scientific and project content at the centre of the experience.

## What it provides

- Configurable identity, colour palette, menus, social links, homepage sections, and footer content.
- Automatic light and dark modes with a manual three-state theme control.
- Project status labels, tags, reading time, tables of contents, RSS, and social metadata.
- Keyboard navigation, semantic landmarks, a skip link, visible focus states, reduced-motion support, print styles, and no-JavaScript fallbacks.
- An example site, GitHub Pages deployment workflow, release automation, and usage documentation.

The theme has no external fonts, JavaScript libraries, trackers, or additional frontend build tools. It requires Hugo 0.123.0 or newer and works with standard or extended Hugo editions.

Version **v0.1.0** was released on 24 October 2026 and is the current project status. The theme is licensed under the Apache License 2.0. Its accessibility features provide a considered foundation, but site owners remain responsible for accessible content, meaningful alternative text, heading order, link wording, and custom colour choices.
